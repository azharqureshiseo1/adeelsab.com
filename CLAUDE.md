## What this is

Corporate + merchant-acquisition website for **AdeelSab** (ADEELSAB (PRIVATE) LIMITED), a
Pakistani multi-vendor marketplace that is built but **not launched**. The site collects sellers
onto a **pre-launch waitlist**. It is NOT the marketplace (no catalogue/cart/checkout).

- Pakistan only. English + Urdu (RTL, Noto Nastaliq Urdu). No dark mode, no other countries/currencies.
- Audience priority (do not reorder): **local sellers** (onboarding) → **resellers** (waitlist only,
  catalogue not ready) → **dropshippers** (Phase 2 stub).
- Deploy target: **Hostinger Business, Node.js 22, server-mode Next.js from GitHub**. No `output: 'export'`.

## Non-negotiable rules (from the original brief)

1. Every `page.tsx` exports `dynamic = "force-static"`. Never use `cookies()`/`headers()`/no-store fetches in pages.
2. No runtime writes to disk. Leads go to Supabase (`app/api/waitlist/route.ts`, `supabase/schema.sql`).
3. All user-facing copy lives in `content/site.ts` as `{ en, ur }`. Render with `<T v={…} />`.
4. **Never invent numbers** (users, GMV, testimonials, rates). Unconfirmed values live in
   `content/data/facts.ts` as `todo("…")` and render as visible orange `TODO:` markers.
5. Never soften or hide RTO charges, commission or payout timelines.
6. Ask the owner before adding any npm package outside: next, react, tailwind v4, lucide-react,
   @supabase/supabase-js, nodemailer, @next/mdx (+ its loader/react/types), eslint, prettier.
7. Orange is an accent only; max 3 `--brand-gradient` uses per page. Header = dark logo, dark sections = orange logo.
